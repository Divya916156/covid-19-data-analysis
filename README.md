# COVID-19 Data Analysis Using Python

## 📌 Project Overview

This project focuses on exploring and analyzing COVID-19 data using Python. It demonstrates data handling, data cleaning, and exploratory data analysis (EDA) using Python libraries to understand patterns and trends in the dataset.

The dataset is provided as a ZIP archive containing CSV files, which are loaded directly into Python for analysis.

## 🎯 Objectives

- Load and process COVID-19 datasets from a ZIP archive.
- Use Pandas to read and organize data from CSV files.
- Explore the structure and contents of the datasets.
- Perform data analysis to identify meaningful patterns and trends.
- Develop practical skills in Python-based data analysis.

## 🛠️ Technologies Used

- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **ZipFile** – Reading ZIP archives and accessing files
- **Jupyter Notebook** – Interactive analysis and documentation

## 📊 Dataset

The project uses a ZIP archive containing CSV files related to COVID-19.

Python's built-in `zipfile` module is used to access the archive, while Pandas reads the CSV files into DataFrames for further analysis.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Divya916156/covid-19-data-analysis.git
cd covid-19-data-analysis
```

### 2. Install the required libraries

```bash
pip install -r requirements.txt
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the project notebook and execute the cells in order.

## 🚀 How It Works

1. Import the required Python libraries.
2. Specify the path to the ZIP dataset.
3. Identify CSV files contained in the archive.
4. Read the CSV files using Pandas.
5. Store the resulting DataFrames for further analysis.
6. Explore and analyze the data in the notebook.
